## 后续使用

执行 `npm run validate` 进行日常完整验证，执行 `npm run package:source` 生成 `output/github/` 下的源码包、SHA-256 校验和及文件清单。

上传与后续更新按 [GitHub 操作文档](github.md) 进行。本机 Git 仓库使用 `main` 分支；远程仓库地址由项目所有者设置。
